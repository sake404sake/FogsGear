# Fogs Gear

歯車と濃霧を利用して動力を組み立てるブラウザーゲームです。

## 基本操作

- 上部のギアサイズを選び、盤面をクリックしてギアを配置します。
- 上部のレイヤー選択で配置段を選びます。
- PCではギアをクリック、スマートフォンではギアを長押しすると設定吹き出しが開きます。
- 吹き出しの「同軸同期」で、同じ軸のギアを固定・解除できます。
- 「設置段を変更」を開くと、配置後のギアを別レイヤーへ移動できます。
- 変更できる段に同じレイヤーのギアが重なる場合、移動は拒否されます。
- 吹き出し下部にはギア固有IDが表示されます。

## レイヤー

| 段 | 色 |
| --- | --- |
| 1段目 | 金 |
| 2段目 | 銀 |
| 3段目 | 銅 |

同じ座標の別レイヤーにあるギアは同軸として扱われます。
同軸ギアは、「同軸同期」が有効な場合だけ回転状態を同期します。

## ギア接続

### 噛み合い

同じレイヤーでギア同士が接触すると、物理接続になります。
噛み合い接続ではギアのサイズ比によって回転速度が変わります。

### 同軸

同軸固定されたギアは同じ角速度・回転方向で回ります。
同軸上の大きいギアに小さいギアを重ねた場合も、同軸間では減速計算を行いません。

外部ギアやベルトへ動力を出すときは、実際に接続されている同軸ギアのサイズを基準にします。

### ベルト

1. 「ベルト」を選びます。
2. 接続したいギアをクリックします。
3. 同軸ギアの場合は、吹き出しで対象ギアを確認します。
4. 「このギアをベルト対象に追加」を押します。
5. もう一方のギアも同じ手順で追加します。
6. 「ベルトを接続」を押します。

ベルト接続済みのギアは、吹き出しタイトルに `🔗` が表示されます。

ベルトの速度計算は、接続元ギアのサイズを基準にします。

$$
\omega_{target} = \omega_{source} \times \frac{size_{target}}{size_{source}}
$$

小さいギアから大きいギアへベルトを接続すると増速し、大きいギアから小さいギアへ接続すると減速します。

## 可視化

盤面下部の可視化ボタンは、表示だけを切り替えます。ギアの動力状態や接続状態は変更しません。

- `1段目 (金)`: 金レイヤーの表示
- `2段目 (銀)`: 銀レイヤーの表示
- `3段目 (銅)`: 銅レイヤーの表示
- `ベルト`: ベルト線の表示
- `環機構`: 検出された閉路(環機構)の表示

表示をOFFにしたレイヤーのギアは、クリック選択やベルト設定の対象からも外れます。

## 同軸ギアの選択

同軸上に複数のギアがある場合、マウスポインターを重ねると選択中ギアの外周に点線が表示されます。
点線の色はギアのレイヤー色に対応します。

- PC: マウスホイールで同軸ギアを切り替えます。
- スマートフォン: 吹き出しの「同軸ギアを切替」を押します。
- 通常クリックで、現在選択中のギアの設定を開きます。

## 条件制御

「精密・制御」ギアの「処理内容」から「条件制御」を選ぶと、制御内容・実行条件を設定できます。メインギアの停止/起動には対象選択は不要です。同軸同期/解除/切り替えでは、制御ギアと同じ軸にあるギアを選択します。

- 制御内容: メインギアを停止、メインギアを起動、同軸同期、同軸同期解除、同軸同期状態の切り替え
- 回転条件: メインギア稼働中に、制御ギアが指定回数回転するたびに実行
- アイテム条件: メインギア停止中も監視し、指定アイテムの所持数が基準以上/未満のときに実行。反対側へ戻ると再実行できる

メインギアの起動は既存の手動停止状態も解除します。同軸同期/解除は対象軸のギアをまとめて固定/解除し、同期状態の切り替えは現在の状態を反転します。メインギアの固定は解除されません。

## ゴースト表示の色

ギア配置前のゴーストには、接続候補と配置状態が表示されます。

- 緑: 既存ギアへの接続候補あり
- 赤: 接続候補がなく、配置できない状態

接続候補の数によって緑の明るさや輪郭が変わる場合があります。

## 資源

- **Brass**: ギア配置に使う資材です。
- **Steam**: ギアの動力負荷と軸摩擦に使います。
- **動力**: 工業・動力ギアで「動力を蓄積」を選ぶと、1回転ごとに歯数分を蓄積します。
- **Water**: 錬金処理の入力資源です。
- **Fog**: 濃霧から回収する資源です。
- **Brass Stock**: 銅と亜鉛を製錬して作るギア設置用の基本資材です。地形から集めた素材はインベントリの合成画面で加工できます。

ギアの駆動負荷に加えて、未固定の軸には摩擦負荷が発生します。
閉路として認識された環機構内の軸摩擦はゼロとして扱われます。

## スクロール共有

スクロール書庫で共有するスクロールを選び、「QRで共有」からQR画像を保存できます。受け取る側は同じ画面で「QR画像から読み込む」を選び、受け取った画像を指定します。QR画像には設計図データが含まれ、オンライン共有リンクではありません。画像ファイルを渡せる方法で共有してください。

## リセット

設定画面の「ゲームリセット」から「オールリセット」または「強くてニューゲーム」を選びます。オールリセットは保存ギア設計を含む進行データをすべて消去します。強くてニューゲームは保存ギア設計だけを残し、配置ギア、ベルト、資源、建築物、探索進行を初期化します。どちらも初期地点から再開し、ワールドシード・表示設定・スキンは保持します。
リセット後はLLサイズのメインギアが動力源として再生成されます。
どちらもワールドを再読み込みし、初期スポーン位置から再開します。
