# ゲーム音響設計案

> 状態: 同梱した実録音を断片化・反復・速度変更・フィルター・包絡で加工する再生実装があり、地形・設備・床材・線路・車両の88項目すべてに再生レシピを割り当てている。ゲーム本編では移動時の足音、海岸に入った時の水音、床材上の足音、建物メニューを開いた時の設備音を再生する。人によるブラインド識別と音質承認は未実施。
>
> [開発用 実録音ベース試聴ページ](./game-audio-sfx-audition.html) で地形・建築物・線路・車両の現行試作を確認できます。現行試作は人によるブラインド試聴を経ておらず、品質合格の根拠にはなりません。

## 設計の起点

音を「地形名に音色を割り当てる」作業から、「実際の録音を調べ、その音の識別できる特徴を抽出してから、ゲーム用に短く・明瞭にデフォルメする」設計に改める。これまでのノイズと共鳴を個別に足すだけの方法は、音の意味を再現できなかったため主手法として使わない。音の違いは、実音に存在する接触・破砕・水分・機構の時間変化を残して作る。

1. **実音を先に聞く。** 乾いた/湿った足音、靴底と地面、木・石・金属床、実際の設備操作などの参照録音を各音に割り当てる。検索語だけでは選定済みとせず、候補ファイルを実際に再生して採否を記録する。
2. **特徴を記録する。** 発音の順番、過渡音、鳴り続ける長さ、低域の衝撃、高域の粒子音、摩擦、残響、音の休止を記録する。ラベルを見ずに聞いても対象の動作が推測できない場合は、合成へ進まない。
3. **実録音を基にデフォルメする。** 参照音の時間包絡・スペクトル・粒立ちを分析し、必要に応じて録音断片の再合成、粒状処理、時間伸縮、フィルター、共鳴、ノイズ補助を組み合わせる。合成ノイズだけで「泥」「ポンプ」「車輪」などを一から想像して作らない。
4. **素材と状態を分ける。** 石・木・金属などの素材と、乾燥・湿潤・水浸しなどの状態を別要素にする。同じ土でも乾燥土と水を含んだ泥の参照録音を別に用意する。
5. **水がある地面は濡れた音を出す。** 水を含む泥・粘土・沼は、乾いた土の足音に薄い水音を足すだけにしない。濁った接地、泥の押し出し、吸着、足を抜く音を足音の主役にする。水面がある場所だけ短い水はねを加える。
6. **音を鳴らす理由を守る。** 移動成功、製作、運転など実イベントに結びつかない音は鳴らさない。置いただけの建物、採取していない地形、移動していない車両に活動音を付けない。

## 実録音の調達・管理

試聴ページは、原音ファイルをこの作業ツリーに同梱し、ブラウザー内で必要な録音だけを遅延読込して加工再生する。出典・作者・ライセンス・ファイルサイズ・SHA-1は [`manifest.json`](./audio-sources/pdsounds/manifest.json) に記録し、同じページから原音も個別に試聴できる。

| 音源 | 件数 | 再配布条件 |
| --- | ---: | --- |
| [PDSounds.org のパブリックドメイン録音](https://commons.wikimedia.org/wiki/Category:PDsounds.org)（Wikimedia CommonsおよびInternet Archive収録分） | 45 | 収録元のパブリックドメイン公開に基づく。作者と出典は台帳に保持する。 |
| [Footstep on Gravel (Gravity Sound)](https://commons.wikimedia.org/wiki/File:Footstep_on_Gravel_(Gravity_Sound).mp3) | 1 | CC BY 4.0。Gravity Soundの作者表示、ライセンスリンク、速度・帯域・包絡を変更した旨を保持する。 |

合計46ファイル（約35.4 MiB）を同梱し、音源ファイルそのものも配布物に含める。PWAの初回オンラインキャッシュ時にマニフェストから46ファイルをすべてキャッシュし、オフラインでも各プロフィールの音を再生できるようにする。CC BY素材は原音プレーヤーと台帳に作者・ライセンスを表示する。出典ファイルを個別に取り出して再配布するときも、それぞれのライセンスとクレジットを引き継ぐ。素材のファイル名を変えたり台帳から外した状態での配布はしない。

各レシピは、録音中の比較的強い短区間の選択、反復、短い包絡、速度の微変化、ローパス帯域、複数素材の重ね合わせを使う。実装上のレシピ割り当ては88項目すべてにあるが、対応する録音が対象の動作を正しく表すか、ラベルなしで聞き分けられるかは未検証である。特に実録音がない架空設備・素材の組み合わせと、粘液音を含む湿潤足音は暫定のデフォルメであり、泥・設備そのものの録音と同等とは扱わない。音質承認には原音・加工音を対象ラベルを伏せて比較するブラインド試聴と、誤認に基づく修正が必要である。ゲーム本編では、対応する地形・床を歩いたときに一歩分の短い音を再生し、建物・車両のメニューを初めて開いたときに対応する設備音を再生する。ストレージの開閉音は短くし、ほかの設備音は各レシピの音響パターンを再生する。設備音は操作時の再生であり、実際の稼働状態に同期した連続音ではない。

各採用音源について、少なくとも次の情報を台帳に保存する。

| 項目 | 記録内容 |
| --- | --- |
| 対応先 | 試聴カタログのID、表示名、必要なら個別の動作イベント |
| 音源 | 元ページのURL、ファイル名、作者/提供元、取得日、ファイルハッシュ |
| 権利 | 適用ライセンスの名称とURL、商用利用・改変・クレジット条件、利用確認日 |
| 音響観察 | 実音の聞こえ方、時間構造、識別に重要な特徴、採用した区間 |
| デフォルメ | どの特徴を残し、何を誇張/簡略化したか、処理手順・パラメーター |
| 確認 | 音量を揃えたブラインド試聴の回答、修正履歴、合否 |

原音をそのままゲームに出す必要はない。原音から識別に必要な時間・質感の特徴を取り出し、短く、世界観に合うよう誇張した合成音に再構成する。使った加工素材のライセンス条件は、最終的な合成素材にも引き継いで管理する。

## 足音の設計

### 一歩の構成

一歩を次の動作で組み立てる。すべての地形で全層を鳴らすわけではなく、表面の状態に合う層だけを使う。

| 動作 | 聞かせる内容 |
| --- | --- |
| 接地 | 靴底が地面に当たる瞬間。硬い床は明瞭、柔らかい地面は丸く短くする。 |
| 荷重・変形 | 砂の沈み、草葉の圧縮、砂利のずれ、泥の押し出しなど、地面側の反応。 |
| 摩擦・崩れ | 葉や草の擦れ、粒の移動、薄片や破片の転がり。地表に存在しない粒を足さない。 |
| 足の抜け | 湿った土の吸着や水の切れ。乾いた地面では原則鳴らさない。 |
| 空間の返り | 遺跡や屋内の短い反射。屋外の地面自体に長い残響を付けない。 |

歩く速さに合わせて一歩の間隔を決め、同じ音の機械的な連打を避ける。音量差を消すために素材の重さまで均一化せず、移動中に聞き取れる範囲で調整する。

### 湿り気と水音の基準

| 状態・地形 | 足音の主役 | 水音の扱い |
| --- | --- | --- |
| 水分を含む粘土層 | 重く鈍い接地、粘土の「ぐちゅっ」、足を抜く「ぬちっ」 | 粘土の中の水分を表す濁った短い音。水たまりが明示されないため、高い水はねは足さない。 |
| 泥炭地 | 沈み込む低い接地、繊維質の圧縮、湿った吸着と引き抜き | 泥炭の重さと吸着を主にし、塩沼のような水面のはねは抑える。 |
| 塩沼 | 泥の吸着とぬかるみ | 浅い水の押し出しとして小さな「ぴちゃ」を加える。乾いた砂利音は使わない。 |
| 海藻場 | 濡れた植物の柔らかな接地、海藻のまとわりつき | 薄い水の「ぱしゃっ」と濡れた擦れ。泥炭の重い吸着とは区別する。 |
| 油浸地 | 粘性のある滑り・引きずり | 油は水と異なる流体。水はね、泥の吸着音は使わない。 |
| 樹脂林 | 葉・地面の擦れに、わずかな粘着感 | 樹脂のべたつきは短い摩擦で表現し、水音や泥のぬちゃ音を足さない。 |
| 森林・葦原・草地など、地形IDだけでは水分が特定できない地面 | 葉、茎、草、土など地表の素材 | 雨天・水濡れなどの状態データがない間は、水音を勝手に追加しない。 |
| 海・湖沼 | 通常の歩行音なし | 移動不可のため足音は鳴らさず、海岸の波・湖岸の小さな寄せ返しを環境音として扱う。 |

### 地形IDとの対応

現在の地形定義で移動できない海・湖沼には歩行音を割り当てない。残る31地形は、それぞれ次の主材質と動作を基準にする。天候・地表の水分状態がゲームデータに追加された場合は、地形プロファイルを上書きする状態レイヤーとして扱う。

| 地形 | 主な足音の設計 |
| --- | --- |
| 草原 | 靴底の柔らかい接地、草葉の擦れ。 |
| 森林 | 土の接地、落ち葉の乾いた圧縮・擦れ。 |
| 山岳 | 固い接地、小石の不規則なずれ。岩崩れのような大音量にしない。 |
| 砂地 | 沈み込む接地、砂粒の流れ。硬い砂利音を避ける。 |
| 古代遺跡 | 石床の短い接地音。残響は場所の空間特性として別に加える。 |
| 鉄鉱脈 | 重い地面の接地、鉄鉱片の短い硬い衝突。持続する金属音程は避ける。 |
| 銅鉱脈 | 接地と銅鉱片の衝突。鉄鉱より丸い粒の密度と減衰で区別する。 |
| 石炭層 | 柔らかい地面、石炭片の崩れ。金属的な響きは使わない。 |
| 硫黄鉱床 | 固い接地、細かな乾いた粒の擦れ。 |
| 粘土層 | 湿った接地、泥の押し出し、粘着した足の抜け。 |
| 石灰岩層 | 粉っぽい硬い接地、細かな石灰粒の崩れ。 |
| 泥炭地 | 深く柔らかい接地、湿った圧縮、遅れて聞こえる吸着と引き抜き。 |
| 塩沼 | ぬかるみの吸着、浅い水の押し出しと小さな水はね。 |
| 油浸地 | 滑る接地と粘性のある引きずり。水はねに聞こえない音にする。 |
| 麻草地 | 地面の接地、茎の軽い折れ・擦れ。 |
| 葦原 | 柔らかな地面、長めの茎のしなりと擦れ。硬い打音を避ける。 |
| 火山灰地 | 軽く沈む接地、細かな灰の移動。砂利や火花に聞こえない音にする。 |
| 磁鉄鉱脈 | 重い接地、細粒の擦れ。磁性を音程で表さない。 |
| 雲母露頭 | 固い接地、薄片がわずかにずれる音。ガラスの高音を強調しない。 |
| 黒曜石地 | 硬い接地、鋭い破片の短い移動音。危険な破砕音を過剰にしない。 |
| 軽石地 | 多孔質で軽い圧縮・崩れ。密度のある岩音にしない。 |
| 海藻場 | 濡れた植物の接地、水の薄いはね、海藻のまとわりつき。 |
| 錫鉱脈 | 接地、細かな鉱石片の硬い衝突。金属板の打音にはしない。 |
| 亜鉛鉱脈 | 接地と鉱石片のずれ。錫・鉄とは粒の密度と減衰で区別する。 |
| 水晶脈 | 固い接地、水晶片の短い衝突。澄んだ高音を連打しない。 |
| 菌糸群落 | 柔らかな有機質の接地、菌糸層の圧縮。水分が明示されない限り水音は足さない。 |
| 薬草地 | 柔らかな接地、葉の擦れ。 |
| 樹脂林 | 土と葉の接地、樹脂の短い粘着摩擦。 |
| 機械の残骸 | 不安定な金属板のたわみ、破片の沈みと短い揺れ。 |
| 飛行船の墜落跡 | 布・木枠・ロープの沈みや擦れ。機械残骸の金属板音と分ける。 |
| 基礎 | 定義された床材の硬い接地。床材が不明なら短い共通の石・コンクリート音。 |

## 環境音・設備・車両

環境音と動作音を別トラックの役割として設計する。水辺の波、火の燃焼、設備の動作音を「場所にいる間ずっと鳴る一つの効果音」にまとめない。状態が取れない対象は音を付けず、必要な状態データが揃ってから接続する。

| 対象 | 音の設計と再生条件 |
| --- | --- |
| 海岸・湖岸 | 海岸はゆっくり寄せる波と泡、湖岸は小さな寄せ返しと間欠的な滴り。地面の足音とは別にし、移動不可の海・湖沼では足音を出さない。 |
| 炉・窯 | 炎の低い燃焼と、間隔・強さの不規則な小さな爆ぜ。火の素材は蒸気の連続音で代用しない。 |
| ボイラー・蒸気設備 | 圧力の変化、弁の開閉、短い排気。圧力・稼働イベントがあるときだけ鳴らす。炎の爆ぜ音と区別する。 |
| 手回しポンプ・水塔・水槽 | 操作・給水・送水時に、機構の力点と水の移動を順に聞かせる。水が流れない状態は静かにする。 |
| 水洗選鉱・蒸留設備 | 機械の動作、液体の攪拌・滴下、処理の節目を分ける。液体の泡だけで機械の稼働を表さない。 |
| 作業台・乾燥棚 | 実際の加工工程に合わせた工具・木材音。待機中の作業音を繰り返さない。 |
| 旋盤・鍛造・掘削設備 | 回転、接触、加工、停止の順序を動作に同期する。連続動作は小さな揺らぎを持たせ、常時最大音量にしない。 |
| 風・浄化・ろ過設備 | 空気の流れと機械の動きを分け、風だけの連続音にしない。 |
| 車両・線路 | 車輪の転がりとレール継ぎ目を移動に同期し、速度で間隔を変える。発車・停止・連結・蒸気排気は個別イベントにする。移動していない車両に走行音を付けない。 |
| オートマタ | 歩行、旋回、作業を分け、それぞれの動作時だけ短い機構音を鳴らす。待機音は必要性が確認できるまで追加しない。 |
| 建築床材 | 足音の床面材として扱い、建物の稼働音と混同しない。金属格子、木板、石、陶器などは接地と余韻の差で聞かせる。 |

## 再生・ミックスと検証

- 足音は移動成功イベント、機械音は実際の工程・状態変化、車両音は移動イベントに結びつける。失敗した移動入力では足音を鳴らさない。
- 短い動作音と環境音を分ける。環境音は単純な短いフレーズのループに聞こえないよう変化させ、動作音が埋もれない音量関係にする。
- 音源の重なりは「プレイヤーの動作」「近くの明確な機械動作」「環境音」の順に優先する。距離が取れる場合は遠くの音を小さく・暗くし、遠距離・画面外の音を停止する。
- 試聴ページで31種の歩行可能地形と、床材・設備・車両57項目を確認する。自動評価は登録漏れ、音量、無音、クリッピング、似すぎた波形を検出する補助であり、ぬかるみ・水はね・素材感の正しさは人が試聴して判定する。
- 技術検査のPASSは音質合格として表示しない。各サンプルは、ラベルとボタン名を隠し、同じ大分類から選んだ4択でブラインド試聴する。試聴者5人全員が全サンプルを一度ずつ聞き、各サンプル4/5以上の正答を合格とする。正答率・試聴人数・候補セット・録音IDを音源台帳に残し、誤答されたサンプルは音を修正して再試験する。
- 実録音の参照元、ライセンス、加工記録がないサンプルは、数値評価や担当者の主観で合格にしない。品質承認には「参照音の確認」「合成音のブラインド識別」「聞き間違いに基づく修正」の全記録を必要とする。
- 湿潤地の回帰確認では、粘土・泥炭・塩沼・海藻場のそれぞれに適切な湿った動作があること、油浸地に水はねが誤って入らないこと、海・湖沼に歩行音がないことを確認する。
- 開発試作ではユーザー操作後にのみ音を開始し、再生・合成失敗を明示する。ゲーム本編に接続する際は既存の音量設定、バックグラウンド復帰、同時再生上限、スマートフォン実機での聴感を別途検証する。
